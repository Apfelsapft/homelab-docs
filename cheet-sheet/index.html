    Linux Cheat Sheet

    System-Diagnose

    Befehl Beschreibung
    htop Prozesse, CPU, RAM live anzeigen
    docker stats CPU/RAM pro Container live
    df -h Speicherplatz aller Partitionen
    hostname Eigenen Hostnamen anzeigen
    uptime Laufzeit + Load Average
    ps aux \| grep X Bestimmten Prozess suchen
    watch -n 2 'cmd' Befehl alle 2 Sekunden wiederholen

    Docker

    Befehl Beschreibung
    docker compose up -d Container starten (Hintergrund)
    docker compose down Container stoppen
    docker compose down --timeout 10 Stoppen mit max. 10 Sek. Wartezeit
    docker stats Ressourcenverbrauch live
    docker exec CONTAINER cmd Befehl in laufendem Container ausführen
    docker logs CONTAINER Logs eines Containers anzeigen
    lazydocker Docker TUI-Manager

    Dateisystem & Speicher

    Befehl Beschreibung
    df -h Speichernutzung anzeigen
    ncdu Interaktiver Verzeichnis-Größen-Browser
    ls /dev/dri GPU-Geräte prüfen (Hardware-Transcoding)
    sudo growpart /dev/sda 3 Partition erweitern
    sudo pvresize /dev/sda3 Physical Volume erweitern
    sudo lvextend -l +100%FREE /dev/mapper/ubuntu--vg-ubuntu--lv Logical Volume auf Maximum erweitern
    sudo resize2fs /dev/mapper/ubuntu--vg-ubuntu--lv Dateisystem nach LV-Erweiterung anpassen
    fsck -y /dev/mapper/ubuntu--vg-ubuntu--lv Dateisystem reparieren (Recovery/initramfs)

    Dateien & Berechtigungen

    Befehl Beschreibung
    chmod +x datei.sh Datei ausführbar machen
    chown user:group pfad Besitzer ändern
    nano datei Datei im Editor öffnen
    cat datei Dateiinhalt anzeigen
    find /pfad -name "*.tar.gz" -mtime +7 -delete Dateien älter als 7 Tage löschen
    find /pfad -name "*.tar.gz" \| wc -l Anzahl Dateien zählen
    tar -czf archiv.tar.gz /pfad Verzeichnis komprimieren

    Cronjob & Automatisierung

    Befehl Beschreibung
    crontab -e Cronjob-Editor öffnen
    crontab -l Aktive Cronjobs anzeigen
    0 4 * * * Zeitplan: täglich um 04:00 Uhr
    >> Ausgabe an Logdatei anhängen (nicht überschreiben)
    2>&1 Fehler ebenfalls in Logdatei schreiben
    cat /var/log/minecraft-backup.log Backup-Log anzeigen

    Cronjob Zeitformat

    *    *    *    *    *
│    │    │    │    └── Wochentag (0-7, * = jeden)
│    │    │    └─────── Monat (* = jeden)
│    │    └──────────── Tag (* = jeden)
│    └───────────────── Stunde
└────────────────────── Minute

    Vollständige Cronjob-Zeile

    0 4 * * * /srv/docker/games/minecraft/backup.sh >> /var/log/minecraft-backup.log 2>&1

    Disk-Erweiterung (Proxmox VM)

    Nach dem Resize in Proxmox diese Befehle der Reihe nach ausführen:

    # 1. Partition erweitern
sudo growpart /dev/sda 3

# 2. Physical Volume erweitern
sudo pvresize /dev/sda3

# 3. Logical Volume auf Maximum erweitern
sudo lvextend -l +100%FREE /dev/mapper/ubuntu--vg-ubuntu--lv

# 4. Dateisystem anpassen
sudo resize2fs /dev/mapper/ubuntu--vg-ubuntu--lv

# 5. Ergebnis prüfen
df -h

    !!! warning "Wichtige Lektionen" - VM-Disks niemals auf der Proxmox System-SSD belassen – immer auf tankmirror verschieben - Backup-Retention immer mit Mindestanzahl absichern (MIN_BACKUPS=3) - fsck im initramfs: fsck -y /dev/mapper/ubuntu--vg-ubuntu--lv

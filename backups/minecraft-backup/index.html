    Minecraft Backup

    Übersicht

    Backup Script sichert täglich die Minecraft Weltdaten und alle relevanten Konfigdateien automatisch.
    Backup Pfad /srv/backups/minecraft
    Script Pfad /srv/docker/games/minecraft/data/backup.sh
    Zeitplan Alle 8 Stunden
    Aufbewahrung 7 Tage / Mindestens 3 Backups
    Format .tar.gz

    Gesicherte Dateien

    Datei/Ordner Inhalt
    neue-welt Weltdaten
    server.properties Serverkonfiguration
    ops.json Operator Liste
    whitelist.json Whitelist
    banned-players.json Gebannte Spieler
    banned-ips.json Gebannte IPs
    mods Installierte Mods
    config Mod Konfigurationen

    Backup Script

    #!/bin/bash

MINECRAFT_DIR="/srv/docker/games/minecraft"
BACKUP_DIR="/srv/backups/minecraft"
CONTAINER_NAME="minecraft-mc-1"
TIMESTAMP=$(date +"%Y.%m.%d_%H-%M")
BACKUP_FILE="$BACKUP_DIR/minecraft_$TIMESTAMP.tar.gz"
KEEP_DAYS=7
MIN_BACKUPS=3

mkdir -p "$BACKUP_DIR"

echo "[$TIMESTAMP] Starte Backup..."

# Welt einfrieren
docker exec $CONTAINER_NAME rcon-cli save-all 2>/dev/null
docker exec $CONTAINER_NAME rcon-cli save-off 2>/dev/null
sleep 5

# Backup erstellen
tar -czf "$BACKUP_FILE" \
    -C "$MINECRAFT_DIR/data" \
    neue-welt \
    server.properties \
    ops.json \
    whitelist.json \
    banned-players.json \
    banned-ips.json \
    mods \
    config

# Autosave wieder aktivieren
docker exec $CONTAINER_NAME rcon-cli save-on 2>/dev/null

# Alte Backups löschen – aber mindestens MIN_BACKUPS behalten
BACKUP_COUNT=$(find "$BACKUP_DIR" -name "minecraft_*.tar.gz" | wc -l)

if [ "$BACKUP_COUNT" -gt "$MIN_BACKUPS" ]; then
    find "$BACKUP_DIR" -name "minecraft_*.tar.gz" -mtime +$KEEP_DAYS -delete
    echo "Alte Backups bereinigt (älter als $KEEP_DAYS Tage)"
else
    echo "Warnung: Nur $BACKUP_COUNT Backup(s) vorhanden – nichts gelöscht"
fi

echo "Backup abgeschlossen: $BACKUP_FILE"
echo "Größe: $(du -sh "$BACKUP_FILE" | cut -f1)"

    Cronjob

    # Ausführen alle 8 Stunden
0 */8 * * * /srv/docker/games/minecraft/data/backup.sh >> /var/log/mc-backup.log 2>&1

    Wiederherstellen

    # Backup entpacken
cd /srv/docker/games/minecraft/data
tar -xzf /srv/backups/minecraft/minecraft_DATUM.tar.gz

# Server neu starten
cd /srv/docker/games/minecraft
docker compose down
docker compose up -d

    Bekannte Probleme

    Backup durchführen nicht möglich

    Problem: Beim manuellen Ausführen des Scripts erscheint permission denied für /var/log/mc-backup.log.
    Lösung: Logdatei mit korrekten Rechten anlegen:

    sudo touch /var/log/mc-backup.log
sudo chown ubuntu:ubuntu /var/log/mc-backup.log

    Backup wird nicht automatisch ausgeführt

    Problem: nach einem Tag keine neuen Backups im ordner zu finden, wieder permission denied für /srv/backups/minecraft. Lösung: Backupordner die korrekten Rechte gegeben:

    sudo chown ubuntu:ububtu /srv/backups/minecraft
